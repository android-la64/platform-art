Runs all or a subset of the ART test suite.

  tests                 name(s) of the test(s)

options:
  -h, --help            show this help message and exit
  -t TESTS, --test TESTS

Global options:
  Options that affect all tests being run

  -j N_THREAD           Number of CPUs to use. Defaults to half of CPUs on target and all CPUs on host.
  --timeout TIMEOUT
  --verbose, -v
  --dry-run
  --skip SKIPS          强制跳过指定的测试。
  --no-skips            忽略 knownfailures.json 中的配置，强制运行所有测试（即使已知会失败）。
  --no-build-dependencies
                        Don't build dependencies under any circumstances. This is the behavior if ART_TEST_RUN_TEST_ALWAYS_BUILD is not set to 'true'.
  -b, --build-dependencies
                        Build dependencies under all circumstances. By default we will not build dependencies unless ART_TEST_RUN_TEST_BUILD=true.
  --dist                If dependencies are to be built, pass `dist` to the build command line. You may want to also set the DIST_DIR environment variable when using this flag.
  --gdb
  --gdb-arg GDB_ARG
  --dump-cfg DUMP_CFG   导出控制流图 (Control Flow Graph)，用于分析编译器优化过程。
  --gdb-dex2oat
  --gdb-dex2oat-args GDB_DEX2OAT_ARGS
  --run-test-option RUN_TEST_OPTION
                        透传参数给底层的 run-test Shell 脚本。
                        Pass an option, unaltered, to the run-test script. This should be enclosed in single-quotes to allow for spaces. The option will be split using shlex.split() prior to invoking
                        run-test. Example "--run-test-option='--with-agent libtifast.so=MethodExit'".
  --with-agent WITH_AGENT
                        Pass an agent to be attached to the runtime
  --runtime-option RUNTIME_OPTION
                        透传参数给 ART 运行时 (dalvikvm)。例如：--runtime-option=-Xjitthreshold:0 (修改 JIT 阈值)
                        Pass an option to the runtime. Runtime options starting with a '-' must be separated by a '=', for example '--runtime-option=-Xjitthreshold:0'.
  --dex2oat-jobs DEX2OAT_JOBS
                        指定 dex2oat 编译器的并发线程数。
                        Number of dex2oat jobs
  -a, --all             Run all the possible configurations for the input test set
  --csv-results CSV_RESULT
                        Store a CSV record of all results.
